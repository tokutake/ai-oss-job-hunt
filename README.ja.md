# AI OSS Job Hunt

AI が主体となって OSS の貢献機会を探し、責任ある変更を提案するプロジェクトです。AI が有用な Issue を自発的に見つけ、貢献できるかを調べ、範囲を絞った変更を準備します。人間がレビューで判断や文脈を加え、上流へ提出する前に確認します。

「Job Hunt」は、AI が自ら仕事を探すことの比喩です。AI と人間のレビュアーが責任を持って協働する方法を試します。

[English](README.md)

## 進め方

- AI が貢献価値のありそうな未解決 Issue を主体的に探します。
- Issue、リポジトリのガイド、関連コード、重複 PR、メンテナーの意向を調べます。
- 範囲を絞った変更案を作り、判断の根拠、リスク、検証結果を説明します。
- 人間が課題選定と変更案をレビューし、必要に応じて文脈を補い、修正を依頼します。
- 外部へのコメントや PR は、人間のレビューと明示的な承認後にだけ提出します。
- 却下や見送りも含めて、結果を透明に記録します。

## ワークフロー

1. AI が[候補選定基準](docs/issue-selection.md)を使って候補を探します。
2. [Issue / PR 台帳](TRACKER.md)に候補と重複確認を記録します。
3. Issue、再現手順、期待動作、受け入れ条件を整理して説明します。
4. AI が変更案を作り、範囲・リスク・検証結果を提示します。
5. 人間が[レビュー手順](docs/review-workflow.md)に沿って確認します。
6. 明示的な承認後に、AI が上流プロジェクトへコメントや PR を提出できます。
7. 結果と学びを[活動記録](ACHIEVEMENTS.md)に残します。

## 方針

- 候補の発見は AI が主体となって進めます。
- 着手前と提出前に重複を確認します。
- Issue の目的に沿った小さな変更に絞ります。
- 判断の根拠を説明し、未検証の点を明記します。
- 人間のレビューで判断と誤りの発見を補い、明示的な承認なしに外部提出しません。
- AI と人間それぞれの貢献を正確に記録します。
- うまくいかなかった試みと学びも記録します。
