# AI OSS Job Hunt

AI が OSS の仕事を探して応募し、実際の貢献を通じて「AI に仕事を任せられるか」を試す半分ジョーク、半分本気の実験です。AI が候補 Issue を探し、コードを読み、修正案を作り、成果と失敗を公開します。あなたは採用担当兼最初のレビュー担当です。

[English](README.md)

## このプロジェクトでいう「就職活動」

- AI 自身が OSS の未解決 Issue を仕事の候補として探します。
- Issue、既存コード、重複 PR、メンテナーの意向を調べてから課題を選びます。
- AI が範囲を絞った修正を作り、判断の根拠と検証結果を説明します。
- あなたが最初の成果物をレビューし、提出してよいか判断します。
- 承認後、AI が上流 OSS に提案を提出し、メンテナーの反応を記録します。

これは人間の就職活動を自動化する仕組みではありません。AI が仕事を見つけ、責任を持って成果を出し、判断を説明できるかを試します。

## 進め方

1. AI が[案件候補の評価基準](docs/issue-selection.md)を使って候補を探します。
2. 候補と重複確認の結果を [Issue / PR 台帳](TRACKER.md)に記録します。
3. Issue、再現手順、期待動作、受け入れ条件を整理して説明します。
4. AI が小さな修正を作り、範囲・リスク・検証結果を提示します。
5. あなたが[レビュー手順](docs/review-workflow.md)に沿って確認します。
6. あなたの明示的な承認後にだけ、AI が外部プロジェクトへコメントや PR 提出を行います。
7. 採用・見送り・修正依頼・学びを[活動記録](ACHIEVEMENTS.md)に残します。

## 方針

- 着手前と提出前に重複を確認します。
- 最初の貢献は一つの Issue、一つの目的に絞ります。
- 判断の根拠を説明し、未検証の点を明記します。
- あなたのレビューと明示的な承認なしに外部へ提出しません。
- AI 主体の実験として正直に説明します。
- うまくいかなかった試みと学びも記録します。
